Title: How to Create a Public Activist Directory from Google Form Responses (No Scripts)

Step 1: Prepare the private response sheet

1. Open the Google Form that collects activist information.

1.1.  enable ckeckboxes so that one person can fill only one form.
1..2. set email collection to verified.
1.3. make sure one can edit one's response 
1.4 optionally send email with filled data

2. Go to the Responses tab and add a linked spreadsheet.  (in my case I named sheet  "Touch Me Not")

3. Keep this spreadsheet private. (not needed for public)

4. Confirm that the sheet named âForm Responses 1â contains columns such as Timestamp, Email, Name, Phone, Area, etc.

5. imp: DON'T DELETE, REORDER, EDIT PRIVATE SHEET.  (in short don't touch it anymore. it is fragile)

Step 2: Create the public directory sheet

1. Create a new Google Spreadsheet.

2. Name it âActivistâs Directory (Public)â (or what ever you want).

3. In this public sheet, use Column A to manually type emails that are approved to be shown publicly.

4. Leave Columns B onward empty for automatic data copying.

Step 3: Add the row-copy formula

1. Click cell B2 in the public sheet.
2. Paste the following formula exactly:

=IF(A2="","",
XLOOKUP(
A2,
IMPORTRANGE("PASTE\_PRIVATE\_SHEET\_URL\_HERE","Form Responses 1!B:B"),
IMPORTRANGE("PASTE\_PRIVATE\_SHEET\_URL\_HERE","Form Responses 1!A:Z"),
""
)
)

3. Replace PASTE\_PRIVATE\_SHEET\_URL\_HERE with the full URL of the private response spreadsheet.

4. Press Enter.

5. When prompted, click âAllow accessâ to connect the two sheets.

Step 4: Apply the formula to more rows

1. Select cell B2.
2. Copy it.
3. Paste it down the column (B3, B4, B5, etc.) for as many rows as you may need.
4. Each row will now independently look up the email in the same row of Column A.

Step 5: Use the approval system

1. Type an email into Column A of any row.

2. If that email exists in the private form responses, the full row of data will appear in Columns B onward of the same row.

3. If the email is removed from Column A, the public data for that row disappears, but the private data remains safe.

4. If an email is typed that does not exist in the private sheet, the row will remain blank.

Step 6: Improve public viewing experience

1. Optionally hide Column A in the public sheet to keep the approval mechanism invisible to viewers.

2. Format the timestamp column as Date time so it appears readable instead of as a number.
